# Букварня — SPA (React + Vite + Tailwind CSS)

1. Запустіть API: `cd bukvarnia-server && npm install && npm run dev` (порт 3000, потрібен MONGO_URI у .env).
2. (необов'язково) наповніть базу: `node seed.mjs`
3. `npm install && npm run dev` → http://localhost:5173
Інша адреса API: змінна `VITE_API_URL` (за замовчуванням http://localhost:3000/api/books).
